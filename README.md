# ShadowVoid Safe Assessment Runner

ShadowVoid is a small Python command runner for local security-training and
assessment workflows. The repository is intentionally **safe by default**:
there is no payload downloader, arbitrary code execution, command-and-control,
stealth, anti-debugging, persistence, credential theft, exploitation,
interception, exfiltration, or process injection.

The previous project advertised those capabilities, but the implementation was
also unreliable: it had two divergent entry points, a broken module-path
resolver, an unauthenticated remote loader, insecure XOR crypto fallback,
missing imports, shell injection hazards, and process-injection routines that
reported success without injecting anything. Those behaviors have been removed
rather than made more operational.

## Requirements

- Python 3.10 or newer
- Optional: `pycryptodome` for `core.AES256GCM`

```bash
python3 -m pip install -r requirements.txt
```

## Run

```bash
python3 shadowvoid.py help
python3 shadowvoid.py modules list
python3 shadowvoid.py c2 status
python3 shadowvoid.py c2 generate 3
```

Interactive mode:

```bash
python3 shadowvoid.py
sv> help
sv> modules list
sv> exit
```

`loader.py` is a compatibility entry point and delegates to the same local
runner. It does not fetch or execute remote bytes.

## Commands

| Command | Behavior |
| --- | --- |
| `help` | Show the command reference |
| `modules list` | Show local module load status |
| `c2 status` | Confirm that network C2 is disabled |
| `c2 generate [count]` | Generate deterministic `.example` names for offline fixtures |
| `scan`, `exploit`, `pivot`, `exfil`, `inject` | Return an explicit safe-mode block |
| `clean` | No-op; it does not alter logs or user history |
| `exit` | End the local session |

The module classes retain a small compatibility API, but active operations
return structured `blocked` responses. `ProcessInjector` only provides
read-only process inventory for diagnostics and marks every process as
non-injectable.

## Development checks

```bash
python3 -m compileall -q .
python3 -m unittest discover -v
```

The project ignores generated bytecode and local environment files. The
installer is user-local and does not require root, create services, modify cron,
or establish persistence.
